## Rules for everyone posting

- State the exact price, whether it is once-off, and the end date.
- Always say the offer is limited to 5 projects and first come, first served.
- Never write "unlimited", "guaranteed rankings", "guaranteed traffic" or "while stocks last".
- Never imply that a monthly care plan is required, or that it is discounted.
- Never include Website Redesign in the offer.
- When the campaign ends, stop posting these prices and use the normal price list.
